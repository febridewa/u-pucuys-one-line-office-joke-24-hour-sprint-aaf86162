One short joke about office life, written as a single line of at most 200 characters — the sort of line you send a colleague after a meeting that should have been an email.

> The office printer has been 'warming up' since Tuesday, which officially makes it our most reliable employee: it never actually does anything.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (142 characters, one line, deterministic).
